How gmat-m8 could look after M8b

Five screens drawn with the tokens M8b.1 proposes: the current brand blue and status colours, refined, with Inter and tabular figures for quantities. Phone screens are 360 px wide, the size every step must design for first. The data comes from seed_demo; the interface is shown in English, while the app defaults to Spanish. The charts are drawn by Chart.js 4, the library Q63 settles on, and each has its data table. Switch the theme to see both palettes.

  1. 1The menu is a set of category dropdowns. Click a category to fold or unfold it; the one holding the current page is always open. A category appears only when the person holds one of its entries. No counts in the menu, so a page costs no extra query.
  2. 2The menu can be hidden with the button at the top left; the content then takes the full width. Try it here. The app remembers both choices in a small cookie, so the next page opens the same way.
  3. 3Four tiles, then the charts. Each tile links to the list it counts, already filtered. The change against last week says whether it is good or bad in words and with an arrow, so colour never carries it alone.
  4. 4Counts and durations only. No chart shows a price. Hover a chart for exact values; "Show the data" opens the same numbers as a table, which is also what a browser without JavaScript gets.
